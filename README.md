# GrowWoo

Full-stack application monorepo.

## Project Structure

```text
growwoo/
├── frontend/          # React.js application (powered by Vite)
├── backend/           # Spring Boot application
├── .gitignore         # Monorepo gitignore covering React and Spring Boot
└── README.md
```

## Getting Started

### Frontend (React.js)
1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```

### Backend (Spring Boot)
- The `backend/` directory is prepared for the Spring Boot project.
- You can generate or copy your Spring Boot application (Maven or Gradle) directly into the `backend/` folder.
